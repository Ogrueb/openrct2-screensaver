# v0.2.0: Fixes and a Linux beta

A wallpaper-style live backdrop built on OpenRCT2's title screen. This release fixes a few bugs
found since v0.1.0 and adds a Linux build as a beta.

## Downloads

- **Windows x64** (`openrct2-v0.5.6-openrct2-screensaver-x64-release.zip`): the patched
  `openrct2.exe` and `openrct2.com` (OpenRCT2 v0.5.6 with patches 0001-0015). Replace both files
  in an OpenRCT2 v0.5.6 install, keeping a copy of the stock pair.
- **Linux x64, beta** (`openrct2-v0.5.6-openrct2-screensaver-linux-x64-beta.AppImage`): a whole
  patched OpenRCT2 v0.5.6 with its own libraries, for any current distribution. See README,
  "Installing" → "Linux".
- **Plugin and generator**: in the source archive (`Settings.cmd` on Windows, `./settings.sh` on
  Linux and macOS; Python 3.11+, no packages).

## Fixes

- Screensaver mode: a stock window that was open when the mode started (the Options window, for
  one) stayed on screen over the park. It is now hidden for as long as the mode runs.
- Settings page: a park folder picked with Browse (or typed in) went back to the old one when the
  page refreshed. It is now kept.
- Settings page: a build read "Not built yet" forever when park files carried dates in the future
  (as an unzip in another time zone can leave them). A build now stays current until its inputs
  change.
- Export: a bundle with park files packed every park of the playlist, unticked ones too. Unticked
  parks now go in by name only, as missing ones do.

## Linux (beta)

New: the patched engine for Linux x64, as an AppImage. Unpack it with `--appimage-extract` and run
`squashfs-root/AppRun` (no FUSE needed); point it at your RCT2 files on the first start. The
user folder is `~/.config/OpenRCT2`. The mode's captions fall back to DejaVu, Liberation or Noto
Sans, found wherever the distribution keeps them.

Tested on Fedora under Wayland only. Known limits:

- X11 sessions are untested.
- Sound (the title screen's ride music and its fades) is untested.
- OpenRCT2's scale factor 2.0 (HiDPI) is untested.
- No macOS engine build: on macOS only the Python tools run.
- Turn off Options → Display → "Minimise fullscreen on focus loss" to keep the mode in the
  background when another window takes the focus.

## Upgrading

Replace the engine (Windows: the two executables; Linux: the AppImage), then run Install again on
the settings page. Views set in the editor are kept.
